## 3. Fitur Print Payment Voucher (IN & OUT)

Request awal: bikinin renderan print PV biar sama persis kaya template kertas A4 yang sudah dipakai perusahaan (dikasih contoh PDF asli sebagai referensi).

### Struktur yang dibangun
- `payment-voucher-print.tsx` - dokumen cetak, **HTML/CSS murni** (bukan screenshot/image): kop surat + logo, kotak meta (Tanggal/No. PV/Dibayarkan-kepada atau Diterima-dari - label beda sesuai arah), Nomor Project/PO/Invoice/Faktur Pajak, tabel rincian item (multi-item + baris PPN/PPh kalau ada) + Total, Terbilang, Info Bank (isinya beda per arah - PV Out nampilin rekening penerima, PV In nampilin rekening kita sendiri), blok tanda tangan 3 kolom (Dibayarkan/Disetujui/Dibuat) yang narik gambar tanda tangan asli dari fitur di atas.
- `terbilang.ts` - konverter angka ke kata Bahasa Indonesia dari nol (custom, tanpa library), diverifikasi hasilnya cocok persis sama contoh di PDF referensi (`7.637.410` → "Tujuh Juta Enam Ratus Tiga Puluh Tujuh Ribu Empat Ratus Sepuluh Rupiah").
- `config/company.ts` - data kop surat (nama, alamat, path logo) di satu tempat.
- `@page { size: A4; margin: 12mm }` + `@media print` di `globals.css`, sidebar/navbar/breadcrumb/footer/judul halaman semua otomatis disembunyikan (`print:hidden`) pas mode print.
- Tombol **"Preview & Cetak"** yang sudah ada sebelumnya sekarang men-trigger dokumen ini lewat `window.print()` (browser native print dialog, bisa langsung Save as PDF).
- Data 100% dynamic dari `usePaymentVoucher()` yang sudah ada - tidak ada hardcode, dan flow PV/approval/tax/payment yang sudah ada tidak disentuh sama sekali (komponennya murni presentational, cuma nambah).

### Putaran perbaikan visual (dipandu screenshot user, dibandingkan ke PDF referensi)
- Baris Total: hapus teks "Total", cukup angka bold (nirukan referensi yang gak ada labelnya).
- Blok tanda tangan: label "Dibayarkan/Disetujui/Dibuat" rata kiri (bukan center), cuma nama+garis yang center.
- `print-color-adjust: exact` - browser defaultnya gak nge-print warna background sama sekali, jadi shading abu-abu di header tabel hilang kalau gak dipaksa.
- Fallback teks kalau logo gagal dimuat (belum ada file / 404) - biar gak nongol ikon gambar rusak.
- Judul "PAYMENT VOUCHER (IN/OUT)": underline dipendekin ngikutin lebar teks aja (bukan garis penuh selebar halaman), ukuran+ketebalan naik jadi `font-black`.
- Shading tabel dipertegas ke `bg-gray-200`, header tabel di-uppercase.
- Kolom kotak meta (Tanggal/No. PV/pihak terkait) dibikin lebar sama rata kiri-kanan (`table-fixed` + `w-1/2`), sebelumnya lebarnya ngikut panjang teks jadi kelihatan miring.
- Teks nama perusahaan yang dobel di bawah logo dihapus (logo image-nya sendiri sudah ada caption nama perusahaan di dalam gambarnya).
- Gap "Nomor Project" dkk diturunin (`mt-4` → `mt-8`), baris PPN/PPh di tabel rincian dirata-kanan.
- Info Bank/metode pembayaran awalnya cuma tampil buat PV Out - dilengkapi juga buat PV In (nampilin `senderBank` = rekening penerimaan kita sendiri).

### Bug ditemukan & diperbaiki
1. **Judul halaman ikut ke-print** ("Detail PV In" dkk) - komponen `PageHeader` (dipakai di semua halaman) belum di-`print:hidden`. Fix sekalian di komponennya, otomatis kefix untuk semua halaman yang pakai.
2. **Ikon petir pojok kiri bawah ikut ke-print** - itu indikator dev bawaan Next.js. Dimatikan lewat `devIndicators` di `next.config.ts` (perlu restart dev server karena `next.config.ts` gak di-hot-reload).
3. **Ikon bulat warna-warni pojok kanan bawah ikut ke-print** - ternyata tombol React Query Devtools (`@tanstack/react-query-devtools`, dipasang buat debugging), bukan ekstensi browser kaya dugaan awal. Disembunyikan pas print lewat CSS target class `.tsqd-parent-container`.
4. **Band abu-kebiruan di bagian paling atas hasil print** - akar masalahnya: tombol "Preview & Cetak" yang `print:hidden` tetap dihitung sebagai sibling sama utility `space-y-4` Tailwind (soalnya `space-y` cuma ngecek struktur DOM/atribut `hidden`, bukan `display:none` dari class), jadi dokumen print di bawahnya tetap kena margin-top kosong. Fix dua lapis: (a) pindahin urutan elemen supaya dokumen print jadi anak pertama (gak kena margin sama sekali), (b) tambahan `print:bg-white` di pembungkus layout sebagai jaring pengaman.
